# Seed Data

Run with:

npm run seed

This wipes and recreates all collections (User, Post, Comment, Like, Follow)
with realistic fictional data - 6 users, a non-trivial follow graph, several
posts each with staggered timestamps, randomized likes, and randomized
comments.

All seeded accounts share the password: password123

Seeded usernames: ada, grace, alan, margaret, katherine, dennis

No real people's personal data is used - names are historical computing
figures used purely as recognizable, non-sensitive placeholder identities.
